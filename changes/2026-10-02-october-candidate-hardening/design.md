# Design boundaries

Keep existing compatibility facades and typed runtime/generation/catalog layers. Make bounded repairs at the original contract boundaries. Tests must exercise the observed failure, including real HTTP transport and the actual JS extension where helper-only tests missed behavior.

Independent ownership: launch/config/process/manager; projector metadata; client HTTP deadlines; discovery/live generation UI; onboarding/package CI. Parent owns integration, report, plan, Linear, live host, and final evidence. No agent changes the live Windows clone.

Do not weaken path containment, ownership authority, exact router identity, secret handling, terminal release or stale-event rejection. Avoid new public nodes and dependencies.
